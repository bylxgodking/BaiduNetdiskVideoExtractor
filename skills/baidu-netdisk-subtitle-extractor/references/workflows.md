# 各脚本操作流程与产物

所有脚本均为「登录 `pan.baidu.com` → F12 Console → 整段粘贴 → 回车」。原项目的 `转存.txt` / `end.txt` 内容其实是 JS，本 Skill 已改名为 `.js`；`6.txt` 为空文件，未收录。

## A. `subtitle-batch-export.js`（主流程）

### 启动

1. 登录百度网盘网页版，进入目标目录。群模式先在网页点开对应群的「文件库」并浏览目录，让页面的真实请求可被脚本嗅探。
2. 打开 F12 → Console，粘贴整段脚本并回车；右下角出现「百度网盘 · 字幕批量导出」面板，日志提示「面板已就绪」。
3. 面板顶部「—」「×」可最小化/关闭；脚本重复粘贴会重新初始化面板。

### 来源与目录

- 来源：`我的网盘`（默认）/ `群组共享文件库`。
- 「含子目录」默认勾选；「跟随当前页面」默认勾选，以 800 ms 定时器同步页面目录变化（群模式隐藏该选项）。
- 目录：点「浏览选择…」打开目录树弹窗，懒加载子目录，可多选；提供「根路径 / 上级 / 回到当前页面目录 / 名称过滤 / 选中当前层全部 / 把当前根加入选择 / 清空选择」。确定后写回选择并触发重扫。「用当前页面目录」直接取 `location.hash` 的 `path`；「清空」清空选择。
- 群模式目录树来自 `groupList → listshare → shareinfo`，节点 key 为 `gid|msg_id|uk|fs_id`；顶层项取不到时先回网页浏览「文件库」，再点「刷新群组」。

### 参数

| 选项 | 值 / 默认 |
|---|---|
| 轨道 | `中文优先`（默认）/ `第一条` / `全部轨道` |
| 格式 | `纯文本 TXT`（默认）/ `SRT（带时间轴）` / `两种都要` |
| 拆分 | `每个文件夹一个文件（按目录分层）`（默认）/ `每个视频一个文件` / `全部合并成一个文件` |
| 并发 | 默认 3，范围 1–8 |
| 间隔 | 默认 300 ms |
| 只处理失败的 | 配合「重试失败」使用 |
| bdstoken | 留空自动获取；失效时手填 |

### 扫描、诊断、导出

1. 「扫描视频」递归列出视频，结果表格显示状态并支持逐条勾选 / 「全选/不选」。
2. 「接口诊断」对第一个视频逐组试探字幕接口，打印每组响应前 200 字与解析到的轨道；群模式会先提示是否已抓到请求模板。
3. 「查看嗅探」打印最近 12 条命中请求并把全部结果复制到剪贴板；「导出诊断」下载 `百度网盘-诊断数据.txt`（状态、顶层群项、日志、最近 25 条请求 URL + 响应）。
4. 「开始导出」按并发抓取字幕，进度条与日志实时更新；「停止」中止，「重试失败」只处理失败项。日志汇总「成功 / 无字幕 / 失败」。
5. 有成功项时自动调用「打包下载 ZIP」。JSZip 从 4 个 CDN 依次加载（bootcdn / staticfile / jsdelivr / unpkg，版本 3.10.1）；全部失败则降级「逐个下载」。
6. 手动导出：「打包下载 ZIP」「下载合并文稿」（单个 TXT）「逐个下载」（每 700 ms 一个文件，浏览器需允许多文件下载）。

### 产物

- `<目录名>-字幕.zip`（群模式为 `群文件字幕-字幕.zip`）：`文本稿/*.txt`、`srt/*.srt`；按视频拆分时用视频相对路径，按全部合并时生成一个合集文件；多选目录时前缀补根目录名。
- 每个文本文件写入 `\uFEFF` UTF-8 BOM；文件名过滤 `\/:*?"<>|` 与控制字符并截断到 80 字符；重名自动加 `_2`。
- TXT 中每个视频以 `## 标题` 开头，附 `> 轨道：… ｜ 共 N 条`、正文、`---` 分隔。
- 诊断文件 `百度网盘-诊断数据.txt` 不含视频本体，但含 URL 与响应片段。

### 编程接口

脚本暴露 `window.__BD_SUB__`：

```js
__BD_SUB__.scan()          // 扫描
__BD_SUB__.probe()         // 接口诊断
__BD_SUB__.run()           // 开始导出
__BD_SUB__.exportZip()     // 打包 ZIP
__BD_SUB__.exportMerged()  // 合并文稿
__BD_SUB__.exportDiag()    // 导出诊断
__BD_SUB__.loadGroupRoot() // 加载群顶层项
__BD_SUB__.state           // 当前状态、视频列表、选中项
__BD_SUB__.sniff           // 嗅探到的请求与模板
```

## B. `group-transfer-compare.js`（推荐：先对比再转存）

来源 `转存.txt`。用途：把群共享文件递归转存到自己的网盘，先扫描目标目录对比已存在文件，实现跳过/断点续传。

1. 在浏览器中打开群「文件库」，从 Network 中复制一次成功请求的 `bdstoken`、`logId`、`dp-logid`，以及 `gid`、`msg_id`、`from_uk`、源文件夹 `fs_id`。
2. 只在**本机 Console** 中修改 `CONFIG` 的 `PASTE_` 占位值：`source_fs_id`、`source_path`（根目录留空）、`target_root`、`from_uk`、`msg_id`、`gid`、`bdstoken`、`logId`、`dp-logid`。脚本启动时会检查全部占位值，未填完直接报错退出。
3. 六步流程：扫群目录 → 扫我的网盘目标目录 → 对比已存在 → 按目标目录分组 → 批量转存（每批最多 500，失败重试 3 次，间隔 500 ms）→ 完成。
4. 结果写到 `window.__BAIDU_TRANSFER_COMPARE__`（对比结果）与 `window.__BAIDU_TRANSFER_RESULT__`（转存结果），并有浮动进度框。

## C. `group-transfer-recursive.js`（备选：按目录递归）

来源 `end.txt`。用途：按目录逐个创建并转存，不做目标目录对比，适合首次全量转存。

1. 填写 `CONFIG`：`from_uk`、`msg_id`、`gid`、`root_fs_id`、`target_root`、`create_bdstoken`、`create_dp_logid`、`transfer_bdstoken`、`transfer_logId`、`transfer_dp_logid`；全部为 `PASTE_` 占位，未填完会早停并把运行状态复位。
2. 参数：`batch_size=500`、`delay=500`、`max_retry=3`；防重复运行标记 `window.__BAIDU_RECURSIVE_TRANSFER_RUNNING__`。
3. 流程：`/mbox/msg/shareinfo` 递归读群目录 → `/api/create` 创建同名目录 → `/mbox/msg/transfer` 按目录批量转存 → 浮动面板显示进度与失败清单。
4. 结果写到 `window.__BAIDU_RECURSIVE_TRANSFER_RESULT__`。

转存完成后回到主脚本，切换「我的网盘」模式重新扫描并导出字幕。

## D. `batch-rename.js`

来源 `rename.js`。右下角面板流程：粘贴运行 → 设置规则 → 扫描预览 → 勾选 → 开始执行 → 复扫验证。

- 规则：正则替换、去前缀、去后缀、查找替换；默认正则 `^\[\d+\]\s*--\s*`（清理 `[01] -- ` 类课程编号）。
- 命名冲突（`errno 12`）时先删除目标同名文件再改名；删除进回收站可恢复，务必先预览。
- 结果通过重新扫描目录验证；`bdstoken` 自动获取，面板可手填。

## E. `duration-to-xlsx.js`

来源 `run.js`。登录后进入目标文件夹，粘贴运行即以 URL 中的 `path` 为根目录递归扫描视频，逐个请求 `/api/mediainfo` 取 `info.duration`，格式化为时长，注入 `xlsx@0.18.5` 后下载 `百度网盘视频时长.xlsx`。`PAGE_SIZE=100`、间隔 50 ms；无需 bdstoken。
