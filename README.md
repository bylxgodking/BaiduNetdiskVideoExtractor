# BaiduNetdiskVideoExtractor

> 百度网盘视频信息批量提取工具

一个基于浏览器端 JavaScript 的百度网盘视频信息批量提取工具。

它可以自动读取当前百度网盘目录，递归扫描其中的视频文件，并通过百度网盘的媒体信息接口批量获取视频时长，最终导出为 Excel 文件。

**无需下载视频文件本身。**

------

## ✨ 功能

目前主要提供以下功能：

- 📂 自动读取当前百度网盘目录
- 🔍 递归扫描子文件夹
- 🎬 自动识别视频文件
- ⏱️ 批量获取视频时长
- 📊 导出 Excel
- ✂️ 自动去除视频文件后缀
- 💾 不需要下载视频文件
- 🌐 直接在浏览器 Console 中运行

------

## 📊 导出结果

目前导出的 Excel 只保留两个字段：

| 文件名      | 视频时长 |
| ----------- | -------- |
| 01.基础知识 | 01:23:52 |
| 02.极限     | 00:58:31 |
| 03.导数     | 01:15:42 |
| 04.积分     | 02:03:18 |

例如原文件：

```text
01.基础知识.mp4
```

导出后：

```text
01.基础知识
```

`.mp4`、`.mkv`、`.avi`、`.mov` 等视频后缀会自动去除。

# 🚀 使用方法

## 1. 打开百度网盘

使用 Chrome、Edge 等浏览器登录百度网盘网页版。

进入需要处理的视频目录。

例如：

```text
/考研/数学/基础阶段
```

------

## 2. 打开开发者工具

按：

```text
F12
```

进入：

```text
Console
```

------

## 3. 运行脚本

将项目中的 JavaScript 脚本复制到 Console 中执行。

工具会自动读取当前网页 URL 中的目录路径。

例如当前页面：

```text
https://pan.baidu.com/disk/main#/index?category=all&path=...
```

程序会自动获取当前 `path`，无需手动输入目录。

------

## 4. 自动扫描

程序会递归读取当前目录及其所有子目录。

例如：

```text
课程
├── 第一章
│   ├── 01.mp4
│   ├── 02.mp4
│   └── 03.mp4
│
├── 第二章
│   ├── 01.mp4
│   └── 02.mp4
│
└── 第三章
    └── 01.mp4
```

程序会自动找到所有视频。

控制台会显示类似：

```text
📂 扫描：/课程
🎬 找到：01.mp4
🎬 找到：02.mp4
🎬 找到：03.mp4

共找到 156 个视频
```

------

## 5. 获取视频时长

对于每一个视频，程序会请求百度网盘的媒体信息，并读取：

```text
info.duration
```

然后转换为：

```text
HH:MM:SS
```

例如：

```text
5032 秒
```

转换为：

```text
01:23:52
```

------

## 6. 自动生成 Excel

处理完成后会自动下载：

```text
百度网盘视频时长.xlsx
```

Excel 只有两列：

```text
文件名        视频时长
--------------------------------
01.基础知识    01:23:52
02.极限        00:58:31
03.导数        01:15:42
```

# 🔧 工作原理

整个过程不需要下载视频文件。

基本流程：

```text
              百度网盘网页
                   │
                   ▼
            当前目录 URL
                   │
                   ▼
          获取当前文件夹路径
                   │
                   ▼
          获取目录文件列表
                   │
                   ▼
             递归扫描目录
                   │
                   ▼
              找到视频文件
                   │
                   ▼
          获取视频媒体信息
                   │
                   ▼
             读取 duration
                   │
                   ▼
             转换视频时长
                   │
                   ▼
             生成 Excel
```

核心数据流：

```text
文件名
  +
fs_id
  +
文件路径
      ↓
百度网盘媒体信息接口
      ↓
info.duration
      ↓
HH:MM:SS
```

------

# 💾 是否需要下载视频？

**不需要。**

例如一个百度网盘目录中有：

```text
500 GB
```

的视频文件。

本工具不会将这些视频下载到本地。

它主要读取：

```text
文件列表
视频 ID
文件路径
媒体信息
视频时长
```

因此，视频文件本身不会因为执行工具而被下载。

# 🎯 为什么做这个项目？

这是一个从实际需求中产生的小工具。

我当时有一个百度网盘目录，其中存放了大量课程视频。

由于视频数量很多，如果想知道：

```text
一共有多少视频？
每个视频多长？
所有视频总共多长？
```

一个一个打开视频查看时长非常麻烦。

而为了获取这些信息，如果把所有视频全部下载到本地，也没有必要。

所以做了这个工具：

```text
大量百度网盘视频
        ↓
批量提取视频时长
        ↓
导出 Excel
```

我个人主要用它来整理学习资料、统计课程总时长以及制定学习计划。

但**学习计划并不是这个项目本身的功能定位**。

项目本身的核心功能就是：

> **批量提取百度网盘中的视频信息并统计视频时长。**

# 🔐 隐私与安全

本工具运行在用户自己的浏览器环境中。

不需要输入：

- 百度网盘密码
- Cookie
- Access Token
- 账号信息

工具使用当前浏览器已经登录的百度网盘会话访问相关接口。

项目不会主动上传你的文件，也不会下载视频内容。

### 注意

由于本工具需要在浏览器 Console 中执行 JavaScript，请确认代码来源可信后再运行。

不要在浏览器 Console 中随意运行来源不明的脚本。

------

# ⚠️ 注意事项

### 百度网盘接口变化

本项目依赖百度网盘网页端接口。

如果百度网盘修改相关接口，工具可能需要更新。

### 需要登录百度网盘

运行工具前，需要在当前浏览器中登录百度网盘。

### 大量视频

如果目录包含几百甚至上千个视频，需要逐个请求媒体信息，因此处理过程可能需要一定时间。
