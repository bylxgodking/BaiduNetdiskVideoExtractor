# 排障决策树、已知限制与分发检查

## 1. 症状 → 处置

| 症状 | 判断与处置 |
|---|---|
| 大量「无字幕」 | 百度尚未为该视频生成智能字幕。我的网盘：在播放页手动打开一次字幕后重扫；群文件：群共享视频通常不生成字幕，先用 `group-transfer-*.js` 转存到我的网盘再导出。不要对同一批视频反复重试 |
| 群列表 / 顶层项为空 | 群接口必须用 `type=2`；先在网页点开群「文件库」浏览一次，再点「刷新群组」。用「查看嗅探」确认是否抓到 `/mbox/group/listshare` 请求 |
| 有轨道但字幕内容抓取失败 | 字幕直链跨域或需鉴权：脚本已先 `include` 后 `omit` 各试一次。仍失败则改在播放页手动下载，或转存后再导出 |
| `bdstoken` 失效 / 未登录（`111`、`-6`） | 刷新网盘页面重新登录；仍失败时在面板手填新的 `bdstoken`（从页面请求 URL 或 `window.locals.bdstoken` 取得）。错误码含义见 `api.md` |
| `31034` 限流 | 降低并发到 1–2、间隔提高到 800–1000 ms，稍后重试；转存类脚本同样可调 `delay` |
| ZIP 没下载 | JSZip 四个 CDN 都被拦截时会降级「逐个下载」，需允许浏览器多文件下载；也可改用「下载合并文稿」 |
| 群字幕模板一直为空 | 在网页里播放一次该群视频并打开字幕，让脚本 hook 到真实 `streaming` 请求；然后重新点「接口诊断」 |
| 文件名乱码 / 缺失 | 导出统一加 UTF-8 BOM；文件名已从 URL/hash 解码并过滤非法字符、截断 80 字符 |
| 转存脚本一启动就报「请先填写」 | `CONFIG` 中仍有 `PASTE_` 占位值；按 `workflows.md` 从浏览器 Network 取值后在本机填写 |
| 仍无法定位 | 点「导出诊断」下载 `百度网盘-诊断数据.txt`，对照 `api.md` 检查 URL、errno 与响应；外发前删除其中的 token、URL 参数与个人信息 |

## 2. 已知限制

1. **只能浏览器 Console 运行**：相对 URL + `window/document/location`，无 Node/Python 版本；所有 CDN 注入依赖页面网络策略。
2. **群文件字幕无公开接口**：靠嗅探模板 + 3 组试探，成功率不保证；AI 字幕通常只对本盘文件生成，转存是最可靠路径。
3. **接口私有且易变**：`listshare` 的 `type`、`shareinfo` 的记录位置都曾与文档/猜测不同；脚本已按真实抓包校正并做多形态容错。
4. **跨域**：字幕直链可能与 `pan.baidu.com` 不同源，浏览器 `fetch` 会被 CORS 拦截；油猴 `GM_xmlhttpRequest` 可绕过，但本 Skill 不分发第三方脚本。
5. **token 时效**：`bdstoken`、`logId`、`dp-logid`、`msg_id`、`gid` 会过期且账号/群组相关；两个转存脚本必须每次在本机重新填，不要复用他人值。
6. **限流与规模**：并发上限 8、分页 500 页、群目录 guard 200、目录层级 guard 3000；超大目录建议分批选择。
7. **重命名有破坏性**：冲突时会删除同名文件（进回收站），必须先预览、小批量验证。
8. **第三方依赖授权**：JSZip / SheetJS 为运行时 CDN 注入，不打包进本 Skill；上架分发时按其许可说明。
9. **原项目文档过时**：仓库 `README.md` 只描述视频时长 → Excel，声明的 `baidu-netdisk-video-extractor.js` 与 `LICENSE` 文件实际不存在，也未描述字幕导出主功能；不要拿它当商品说明。

## 3. 安全与隐私

- 首次使用向用户说明 Console 粘贴脚本的风险；只使用用户自己审核过的脚本来源。
- 脚本不读取或发送 BDUSS/Cookie，不上传视频或字幕内容；所有请求走用户已登录的浏览器会话。
- `bdstoken`、`logId`、`dp-logid` 等同会话凭据处理：只在本机填写，不写入公开仓库，不贴给第三方 Agent/论坛。
- 诊断文件含完整 URL 与响应片段（可能含 `fs_id`、`uk`、`gid`、token）；分享前逐项清理。
- 转存到自己的网盘会产生真实文件与目录，删除操作进回收站；执行前确认目标路径。
